# Security Policy

## Reporting a Security Issue

If you find a security vulnerability or security-related issue in this project, please report it through the GitHub repository.

Please provide:

- A clear description of the issue.
- Steps to reproduce the issue.
- Any relevant screenshots or error messages.
- Possible suggestions for fixing the issue.

## Responsible Disclosure

Please do not publicly disclose security vulnerabilities before they have been reviewed by the project maintainer.

Thank you for helping improve the security and reliability of this project.
